# RAON-1 Portfolio

개인 이력, Entry 프로젝트, Vibe Coding 프로젝트, 자격증, 수상경력, GitHub 작업을 한곳에서 보여주는 포트폴리오입니다.

## 구조

- `index.html` — 첫 화면과 전체 섹션
- `css/` — 반응형 디자인
- `js/portfolio-data.js` — 포트폴리오 내용을 추가·수정하는 핵심 데이터
- `js/main.js` — 화면 렌더링
- `data/` — 향후 데이터 관리용 JSON 템플릿
- `projects/entry/` — Entry 프로젝트 파일 연결 위치
- `projects/vibe-coding/` — Vibe Coding 프로젝트 연결 위치
- `assets/images/` — 프로필·프로젝트·자격증·수상 이미지 위치

## 프로젝트 추가 방법

1. `js/portfolio-data.js`의 `projects` 배열에 프로젝트를 추가합니다.
2. GitHub 주소나 실제 데모 주소를 연결합니다.
3. Entry 파일이나 웹 프로젝트 파일은 `projects/` 아래에 보관할 수 있습니다.
4. 나중에 GitHub Pages를 켜면 웹에서 바로 포트폴리오를 볼 수 있습니다.

현재 연결된 저장소:
- eng
- trans
- jusik

개인 정보, 경력, 자격증, 수상경력은 실제 내용을 받은 뒤 추가하도록 비워 두었습니다.
